The Methodology

  1. 1. Capture beats inference. A HAR export from a live browser session (149 chunks, 12.8MB) outperformed every attempt to fetch the shell from outside. When the renderer strips scripts, proxies die, and archives time out — capture at the source.
  2. 2. Descriptors are the schema. Protobuf clients ship their own documentation as base64 FileDescriptorProto blobs. A 30-line varint walker + strict TLV parser (not regex) extracted the full RPC catalog — exact service/method names, zero guessing.
  3. 3. Probe error surfaces deliberately. 401s, 400s, and 404s each carry structured lessons (Part 1's taxonomy). The server *wants* to tell you the schema — buf.validate violations name fields.
  4. 4. Collaborator captures are force multipliers. The single biggest unlock (Part 5's framed-RPC send) came from a teammate's 2026-07-21 capture with the exact note: "request body is NOT raw JSON — Connect-protocol streaming framed." Three prior turns of enum-guessing collapsed to one line of truth. Publish your notes.
  5. 5. Test against live state, then fresh-process verify. In-session caches (sys.modules) produced stale results that looked like code bugs more than once. The raw-dump check caught it every time.
